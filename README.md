# טאבו — משחק הנדל״ן הישראלי

משחק לוח נדל"ן מקוון ל-2–6 שחקנים, בעברית מלאה ו-RTL, עם ערים בישראל
ושיחת וידאו במרכז הלוח.

**אפליקציה עצמאית.** אין לה תלות בפלטפורמת einit — סטאק משלה, Supabase משלה,
דיפלוי משלה. היא יושבת בריפו הזה רק לנוחות; `git subtree split` מוציא אותה
לריפו נפרד בכל רגע.

היקף שלב א': **דסקטופ בלבד · שימוש אישי · חדרים פרטיים בלינק הזמנה.**

## הרצה

```bash
npm install
npm run dev        # שרת פיתוח
npm run test       # vitest
npm run typecheck  # tsc
npm run build      # בנייה לפרודקשן
```

## מבנה

```
data/board.json     נתוני הלוח — 40 משבצות, 8 קבוצות צבע, 32 קלפים
docs/spec.md        מפרט מלא: IP, ארכיטקטורה, חוקים, RTL
src/lib/geometry.ts מיפוי מיקום 0–39 לרשת 11×11 (למה הלוח לא מתהפך)
src/lib/format.ts   עיצוב שקלים (למה ₪ נכתב לפני הספרות)
src/components/     הלוח, המשבצות, מרכז הווידאו
```

- [ ] שלב 2 — סכימה + `game_action()` אטומי
- [ ] שלב 3 — מנוע: תנועה, קנייה, שכ"ד, כלא, קלפים
- [ ] שלב 4 — Realtime: שידור, הצטרפות, חיבור מחדש
- [ ] שלב 5 — בנייה, משכון, סחר, מכרזים, פשיטת רגל
- [ ] שלב 6 — וידאו mesh + סיגנלינג פר-שחקן
- [ ] שלב 7 — ליטוש

הסדר לא שרירותי: **שלב 0 חוסם את כל השאר.** כל הארכיטקטורה נשענת על הנחה
שהתיעוד של Supabase לא אומר במפורש — ש-`realtime.send()` בתוך טרנזקציה הוא
אטומי איתה. אם ההנחה שגויה, שידור יכול להצליח בזמן שהמהלך נכשל, וכל הלקוחות
ייתקעו על מצב שאינו קיים.

## הערה על שמות

השם, שמות הפינות ("זינוק", "מעצר בית", "חופשה באילת", "הוצאה לפועל") ושמות
החפיסות ("יד הגורל", "קופת גמל") אינם תרגומים — הם נבחרו כך במכוון. שמות
התשתיות גנריים ("תחנת הכוח", "נמל הים") כי החלופות המתבקשות הן סימנים מסחריים
ישראליים חיים. הנימוק המלא ב-`docs/spec.md` §2. יש טסט שאוכף את זה.
