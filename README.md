# טאבו — משחק הנדל״ן הישראלי

משחק לוח נדל"ן מקוון ל-2–6 שחקנים, בעברית מלאה ו-RTL, עם ערים בישראל
ושיחת וידאו במרכז הלוח.

**אפליקציה עצמאית.** אין לה תלות בפלטפורמת einit — סטאק משלה, Supabase
משלה, דיפלוי משלה. `git subtree split` מוציא אותה לריפו נפרד בכל רגע.

היקף: **דסקטופ בלבד · שימוש אישי · חדרים פרטיים בלינק הזמנה.**

---

## הרצה

```bash
npm install
npm run dev          # שרת פיתוח — משחק מקומי עובד מיד, בלי Supabase
npm run test         # 195 טסטים
npm run typecheck
npm run build
npm run build:engine # מקבץ את המנוע ל-Edge Function
npm run build:single # אורז לקובץ HTML אחד — dist/tabu.html
npm run db:test      # בדיקות SQL מול Postgres מקומי
```

משחק מקומי (כל השחקנים על מסך אחד) עובד ללא שום תשתית — אין שרת, אין
קריאות רשת חוץ מהפונטים, וכל המנוע רץ בדפדפן. `npm run build:single`
אורז אותו לקובץ HTML יחיד שאפשר לפתוח ישר מהדיסק או לשלוח למישהו.

למשחק אונליין עם וידאו ראו [`docs/deploy.md`](docs/deploy.md).

## איך זה עובד

**המנוע הוא פונקציה טהורה.** `reduce(state, action, ctx)` מחזיר מצב חדש
ואירועים. לא נוגע בשעון, ברשת או ברנדום — `now` והזרע נכנסים מבחוץ. לכן כל
משחק ניתן לשחזור מלא מהזרע, ואפשר לבדוק אותו במאות טסטים בלי תשתית.

**הסמכות בשרת.** הלקוח שולח *פעולה*, לא מצב. Edge Function מריצה את אותו
מנוע ומתחייבת. אי אפשר לרמות בקוביות, ביתרה או בבעלות — הדפדפן פשוט לא
מחשב אותן. יש טסט RLS שמוכיח שלקוח לא יכול לכתוב לטבלת המצב ולא לקרוא
ל-`commit_move`.

**אטומיות בלי נעילה פסימית.** `commit_move()` עושה עדכון מותנה על `version`,
כותבת את יומן האירועים ומשדרת — הכל בטרנזקציה אחת. שני כותבים מקבילים
שקראו את אותה גרסה מסתיימים באחד מוחל ואחד `STALE`. מאומת מול Postgres
אמיתי ב-`npm run db:test`.

**הווידאו נבדק, לא רק נכתב.** שכבת הסיגנלינג מופשטת: אותו `PeerMesh` רץ
מול Supabase Realtime בפרודקשן ומול `BroadcastChannel` בין כרטיסיות
בפיתוח. בלי התעבורה המקומית, קוד ה-WebRTC היה נבדק לראשונה רק
בפרודקשן — וכך נתפס באג אמיתי: יצירת הצעה ידנית התנגשה עם
`negotiationneeded` והפילה את המשא ומתן.

**וידאו ישיר בין השחקנים.** המשבצות במרכז הלוח קטנות וכולן באותו גודל,
ולכן אין צורך ב-simulcast — מה שבדרך כלל הורג mesh. התמורה: ישראלים
מדברים עם ישראלים ב-5–20ms, לעומת 100–130ms דרך פרנקפורט בכל SFU מנוהל,
ובעלות אפס.

## הערה על שמות

השם, שמות הפינות ("זינוק", "מעצר בית", "חופשה באילת", "הוצאה לפועל")
ושמות החפיסות ("יד הגורל", "קופת גמל") אינם תרגומים — הם נבחרו כך במכוון.
שמות התשתיות גנריים ("תחנת הכוח", "נמל הים") כי החלופות המתבקשות —
רכבת ישראל, נתב"ג, חברת החשמל, מקורות — הן **סימנים מסחריים ישראליים
חיים**, כלומר חשיפה שנייה ובלתי תלויה בזו של Hasbro.

המחירים נגזרו ממחירי דירות בפועל (למ"ס, רבעון 4 2025) ולא מהמספרים
הקלאסיים. הנימוק המלא ב-[`docs/spec.md`](docs/spec.md) §2.
יש טסטים שאוכפים את שני הדברים.
